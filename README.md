# JavaScript DOM Exercises

A collection of JS DOM exercises covering click counters, background changes, image switching, text validation, adding and deleting list items, and more.

## Objective

Use them to test your skills in working with the DOM using JavaScript and enhance your skills in:

- Manipulating HTML elements using JavaScript
- Handling events
- Building interactive UI projects without external libraries
